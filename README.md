# Live Bilingual Captions

> **macOS 26 이상 전용입니다.** 음성 인식·번역을 macOS 26 에만 있는 Apple 프레임워크
> (`SpeechAnalyzer`, `Translation`)로 처리하므로 Windows·Linux·iOS 에서는 동작하지 않고,
> 이식하려면 인식·번역 엔진부터 새로 골라야 합니다. 서명·공증된 배포본은 없습니다 —
> 직접 빌드해서 씁니다.

영어와 한국어 음성을 듣고 원문과 번역을 항상 위에 뜨는 오버레이로 표시하는 macOS 앱입니다.
자막은 발화 하나가 아니라 **최근 발화 목록**입니다 — 말이 끊이지 않아도 이전 문장이
곧바로 사라지지 않고 화면에 남아 읽을 시간을 줍니다.

- 음성 인식(`SpeechAnalyzer`)과 번역(Apple `Translation`)을 **전부 기기 안에서** 처리합니다. 비용 0원.
- 마이크 또는 시스템 오디오(회의·영상)를 듣고, 한·영을 자동으로 판별합니다.
- 서드파티 의존성이 없습니다.

## 빠른 시작

**요구 사항:** macOS 26 이상, Swift 6.2 이상(Command Line Tools 로 충분, 전체 Xcode 불필요).

```bash
git clone https://github.com/MOSW626/LiveBilingualCaptions.git
cd LiveBilingualCaptions
./install.sh   # /Applications 에 설치 → Launchpad·Spotlight 에서 실행
./test.sh      # 테스트 (맨 `swift test` 는 swift-testing 경로 문제로 실패합니다)
```

권한(마이크·화면 기록)을 빌드마다 다시 묻지 않게 하려면 [CLAUDE.md](CLAUDE.md)의
"코드서명 인증서 만들기"를 한 번 따라 하세요.

## 어떻게 만들었나

Claude Code 와 이틀(2026-09-16~17) 동안 만들었습니다.

1. 504줄짜리 단일 파일 시제품에서 출발
2. 브레인스토밍 → 설계서·작업 계획서 먼저 작성 ([docs/superpowers](docs/superpowers))
3. 계획이 기대는 macOS 26 API 가 SDK 에 실제로 있는지 확인한 뒤 코딩
4. 작업 단위로 쪼개 테스트 먼저(TDD) 구현
5. 직접 써 보며 불편한 점을 바로 고치는 반복

구조·데이터 흐름 다이어그램은 [docs/diagrams](docs/diagrams)에 있습니다.

## 개발 및 실행

터미널에서 다음 명령을 실행하면 앱을 빌드하고 바로 시작합니다.

```bash
./run.sh
```

빌드만 하려면 `./build.sh`를 실행합니다. 결과 앱은 `dist/Live Bilingual Captions.app`에 생성됩니다.

## 사용

`dist/Live Bilingual Captions.app`을 더블클릭하세요.

처음 실행할 때 권한 요청은 오디오 소스에 따라 다릅니다.

- **마이크**(기본값): 마이크 권한을 물어봅니다. 거부하면 마이크로는 시작할 수 없다는
  안내가 뜹니다. 설정에서 소스를 시스템 오디오로 바꾸면 그때부터는 마이크 권한 없이도
  바로 쓸 수 있습니다.
- **시스템 오디오**: 마이크 권한과 무관합니다. 대신 macOS가 화면 기록(화면 및 시스템
  오디오 녹화) 권한을 요구하고, 이 권한은 허용한 뒤 앱을 한 번 재실행해야 반영됩니다.

(음성 인식·번역은 `SFSpeechRecognizer`의 별도 "음성 인식" 권한 프롬프트를 쓰지 않습니다 —
온디바이스 `SpeechAnalyzer`와 `Translation` 프레임워크가 처리하며, 위 두 권한 외에 추가로
뜨는 프롬프트는 없습니다.)

- 자막은 한 줄이 아니라 **최근 발화 목록**입니다. 새 문장이 와도 이전 문장을 즉시 지우지
  않습니다 — 가장 아래(최신)가 가장 밝고, 위로 갈수록(오래될수록) 흐려지다가, 설정한
  **유지 시간**(기본 10초) 동안 침묵이 이어지면 한꺼번에 지워집니다. 각 줄은 원문 아래에
  번역이 붙습니다.
- 목록에 남기는 줄 수는 설정의 **표시 개수**(기본 3줄)로 조절합니다.
- 긴 발화는 문장 단위로 쪼개 줄마다 따로 번역합니다. 문장부호가 없이 계속 길어지면
  안전망이 단어 경계에서 잘라 화면을 넘어가지 않게 합니다.
- 자막 창의 빈 곳을 드래그하면 위치를 옮길 수 있습니다. 우측 아래 모서리 손잡이를
  드래그하면 패널 폭을 조절할 수 있고, 폭은 다음 실행에도 유지됩니다.
- `정지`/`시작`으로 듣기를 제어하고 `지우기`로 자막을 비웁니다.
- 인식 언어는 기본이 **자동 모드**입니다 — 한국어·영어 인식기 두 벌을 동시에 돌려
  발화마다 신뢰도가 높은 쪽을 채택합니다(연산은 두 배로 씁니다). 상태줄에 현재 채택된
  언어가 표시됩니다. 언어를 하나로 고정하고 싶으면 설정에서 바꿀 수 있습니다.
- 메뉴바의 "자막" 아이콘에서 `설정…`을 열면 오디오 소스(마이크/시스템 오디오), 인식 언어,
  글자 크기, 표시 개수, 자막 유지 시간 등을 바꿀 수 있습니다.

음성 인식과 번역은 모두 macOS 내장 기능으로 **기기 안에서** 처리됩니다.
설정에서 "LLM 으로 확정 문장 다듬기"를 켠 경우에만, 확정된 문장이 고른 제공자(Anthropic 또는 OpenAI) API로 전송됩니다.
이 기능은 기본적으로 꺼져 있습니다.
