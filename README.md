# Live Bilingual Captions

영어와 한국어 음성을 듣고 원문과 번역을 항상 위에 뜨는 오버레이로 표시하는 macOS 앱입니다.
자막은 발화 하나가 아니라 **최근 발화 목록**입니다 — 말이 끊이지 않아도 이전 문장이
곧바로 사라지지 않고 화면에 남아 읽을 시간을 줍니다.

## 개발 및 실행

터미널에서 다음 명령을 실행하면 앱을 빌드하고 바로 시작합니다.

```bash
./run.sh
```

빌드만 하려면 `./build.sh`를 실행합니다. 결과 앱은 `dist/Live Bilingual Captions.app`에 생성됩니다.

## 사용

`dist/Live Bilingual Captions.app`을 더블클릭하세요.

처음 실행할 때 권한 요청은 오디오 소스에 따라 다릅니다.

- **마이크**(기본값): 마이크 권한을 물어봅니다. 거부하면 마이크로는 시작할 수 없다는
  안내가 뜹니다. 설정에서 소스를 시스템 오디오로 바꾸면 그때부터는 마이크 권한 없이도
  바로 쓸 수 있습니다.
- **시스템 오디오**: 마이크 권한과 무관합니다. 대신 macOS가 화면 기록(화면 및 시스템
  오디오 녹화) 권한을 요구하고, 이 권한은 허용한 뒤 앱을 한 번 재실행해야 반영됩니다.

(음성 인식·번역은 `SFSpeechRecognizer`의 별도 "음성 인식" 권한 프롬프트를 쓰지 않습니다 —
온디바이스 `SpeechAnalyzer`와 `Translation` 프레임워크가 처리하며, 위 두 권한 외에 추가로
뜨는 프롬프트는 없습니다.)

- 자막은 한 줄이 아니라 **최근 발화 목록**입니다. 새 문장이 와도 이전 문장을 즉시 지우지
  않습니다 — 가장 아래(최신)가 가장 밝고, 위로 갈수록(오래될수록) 흐려지다가, 설정한
  **유지 시간**(기본 10초) 동안 침묵이 이어지면 한꺼번에 지워집니다. 각 줄은 원문 아래에
  번역이 붙습니다.
- 목록에 남기는 줄 수는 설정의 **표시 개수**(기본 3줄)로 조절합니다.
- 자막 창의 빈 곳을 드래그하면 위치를 옮길 수 있습니다.
- `정지`/`시작`으로 듣기를 제어하고 `지우기`로 자막을 비웁니다.
- 메뉴바의 "자막" 아이콘에서 `설정…`을 열면 오디오 소스(마이크/시스템 오디오), 인식 언어,
  글자 크기, 표시 개수, 자막 유지 시간 등을 바꿀 수 있습니다.

음성 인식과 번역은 모두 macOS 내장 기능으로 **기기 안에서** 처리됩니다.
설정에서 "Claude 로 확정 문장 다듬기"를 켠 경우에만, 확정된 문장이 Anthropic API로 전송됩니다.
이 기능은 기본적으로 꺼져 있습니다.
